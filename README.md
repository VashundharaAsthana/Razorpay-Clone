# Razorpay Landing Page Clone

A frontend practice project recreating the Razorpay landing page using **HTML, Tailwind CSS, and Vite**.

##  Live Demo

**[View the Live Website](https://vashundharaasthana.github.io/Razorpay-Clone/)**

##  Technologies Used

* HTML
* Tailwind CSS
* Vite
* Git & GitHub
* GitHub Actions
* GitHub Pages

##  Features

* Razorpay-inspired landing page
* Responsive layout for different screen sizes
* Tailwind CSS utility-based styling
* Hover effects and transitions
* Multiple feature sections and cards
* Custom SVG and image assets
* Responsive navigation and UI elements

### Tailwind CSS

* Building responsive layouts using utility classes
* Using custom colors, spacing, typography, and responsive breakpoints
* Creating hover effects and transitions

* Testing production builds with `npm run preview`

### Debugging & Deployment

* Debugging broken image and asset paths

* Deploying a Vite project using GitHub Actions

* Troubleshooting deployment issues and verifying the production website

##  Run Locally

Clone the repository:

```bash
git clone https://github.com/VashundharaAsthana/Razorpay-Clone.git
```

Navigate to the project:

```bash
cd Razorpay-Clone
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run start
```

The project will be available on the local development server provided by Vite.

##  Production Build

To create a production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

##  Deployment

The project is deployed using **GitHub Actions and GitHub Pages**.

The production files are generated using Vite and automatically deployed through the GitHub Actions workflow.
